# 石庭 – Stone Garden

枯山水の石庭をテーマにした**倉庫番スタイルのパズルゲーム**。
岩を押して、苔のある所定の場所に配置してください。

## ゲーム概要

- **ジャンル**: パズル（倉庫番）
- **ステージ数**: 30ステージ（6章 × 5ステージ）
- **操作**: キーボード（矢印/WASD）+ マウスクリック + タッチスワイプ
- **対応**: ブラウザ（HTML5 Canvas、フレームワークなし）

## 遊び方

| キー | 動作 |
|------|------|
| 矢印 / WASD | プレイヤー移動・石を押す |
| Z | 1手戻す（アンドゥ） |
| R | ステージをリセット |
| Esc | ステージ選択に戻る |

**ゴール**: すべての緑の苔スポットに石を押し入れてクリア。

## ファイル構成

```
index.html      ← 開発用（levels.js + game.js を個別読み込み）
levels.js       ← 全30ステージのマップデータ
game.js         ← ゲームエンジン（描画・入力・ロジック）
dist/index.html ← itch.io アップロード用（単一ファイル・約50KB）
```

## 技術スタック

- Vanilla JavaScript（外部ライブラリなし）
- HTML5 Canvas
- LocalStorage（進捗・最少手数の保存）
